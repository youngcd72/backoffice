# 네이밍 약어 사전

DB 테이블/컬럼 및 프론트엔드 Ref/ID 라벨명 네이밍에 사용하는 약어를 관리하는 폴더입니다. 새 약어가 필요하면 아래 두 파일에 먼저 등록한 뒤 사용합니다 (임의 약어 생성 금지).

- [business-abbreviations.md](./business-abbreviations.md) — 업무약어 (2자리, 테이블명 프리픽스)
- [word-abbreviations.md](./word-abbreviations.md) — 단어약어 (3~4자, 테이블명·컬럼명 내부 단위)

## 네이밍 조합 규칙

```
테이블명: {업무약어 2자리}_{단어약어 3~4자}[_{단어약어 3~4자}...]
컬럼명  :              {단어약어 3~4자}[_{단어약어 3~4자}...]
```

예: 사용자 마스터 테이블 `US_USR_M`, 사용자명 컬럼 `USR_NM`

전체 백엔드 네이밍 규칙은 프로젝트 루트의 [CLAUDE.md](../CLAUDE.md)를 참고하세요.
